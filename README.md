# Gestelyo

Landing page React en français, réalisée à partir de la référence visuelle fournie le 8 octobre 2026.

## Démarrer

- `npm install`
- `npm run dev -- --port 5173`
- `npm run build`
- `npm run preview`

## Direction visuelle

Logo ruban G original préservé dans `public/`. Palette Corporate Ocean : navy profond, bleu d’action, accents teal. Composition adaptée à la référence : navigation horizontale, hero à deux colonnes, tableau de bord à droite, secteurs photographiques puis six modules. Typographie Manrope hébergée localement. Les icônes Phosphor identifient les modules et les contrôles conformément à la référence.

## Interactions

Navigation dans dix vues du prototype, recherche de commandes, détail de commande dans une boîte de dialogue native, changement de période du tableau de bord, tâches à cocher, notifications, FAQ et menu mobile. Les cartes de secteur et de module sélectionnent une vue de démonstration.

## Limites explicites

Il s’agit d’une landing page et d’un prototype frontend, sans serveur ERP, authentification ou abonnement. Les chiffres, entreprises et variations sont fictifs et signalés comme tels. Les commandes et tâches ne sont pas persistées. Connexion et tarifs ouvrent une explication transparente de leur disponibilité. Aucun formulaire ne simule un envoi réussi.

Les photographies d’illustration sont servies par images.unsplash.com (bureaux, entrepôt, production, commerce). Elles ne représentent pas des clients ou partenaires. Leur chargement nécessite une connexion réseau. Les polices et les logos sont locaux. Aucune télémétrie applicative ni collecte de formulaire n’est ajoutée.

## Fichiers

- `src/main.jsx` : composants React, contenu français et interactions.
- `src/styles.css` : mise en page, thèmes des modules, adaptation mobile et mouvement réduit.
- `index.html` : métadonnées et point d’entrée.
